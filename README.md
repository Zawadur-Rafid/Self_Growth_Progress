# Self-Growth Skill Tracker

## How to Run
1. Install dependencies: `npm install`
2. Start the server: `npm run start`
3. Open http://localhost:3000

Data is persisted in `localStorage` (key `sg_skills_v1`).

Features:
- Add skills with name, category, target date, notes, and progress%
- Active and Completed tabs
- Color-coded countdown (red/gold/green)
- Stats row showing active, due-soon, and completed counts

Styling: dark background (#0d0f14) with purple/teal gradient accents.
